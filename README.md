# 💻 联想开天（兆芯KX7000）银河麒麟V10 + Windows 10/11 双系统安装全攻略

日常办公用麒麟系统安全合规，但遇到特定 Windows 软件、插件或游戏时难免"水土不服"。别急着换电脑，**银河麒麟 + Windows 双系统**才是信创电脑的最优解！

本教程以**联想开天（兆芯KX7000）**为例，手把手教你如何在保留原厂麒麟系统的基础上，完美加装 Windows 系统。

---

## 🛠️ 一、准备工作（工欲善其事，必先利其器）

### 1. 硬件准备

| 物品 | 数量/要求 | 备注 |
| :--- | :--- | :--- |
| 空白U盘 | 2个 | 容量建议≥16GB，后续需格式化，请确保U盘内无重要文件 |
| 成熟完备电脑 | 1台 | 用于下载镜像和制作启动盘，Windows系统即可 |
| 目标信创电脑 | 1台 | 即你要操作的联想开天电脑 |

### 2. 软件与镜像准备

- **银河麒麟镜像**：前往[麒麟软件官方网站](https://www.kylinos.cn/)下载。⚠️ **注意**：必须严格对照你电脑自带的系统版本！本例中自带为**银河麒麟V10 (SP1)**，且CPU为兆芯（x86架构），因此需下载对应的 **V10 SP1 X86/AMD64** 版本。
- **Windows镜像**：前往[微软官网](https://www.microsoft.com/zh-cn/software-download/)下载 Windows 10 或 Windows 11 的 ISO 镜像文件。
- **Rufus 工具**：搜索下载 [Rufus](https://rufus.ie/)（U盘启动盘制作工具），用于将ISO镜像写入U盘。

---

## 🐉 二、制作麒麟U盘 & 划分磁盘空间

我们需要先进入麒麟的 Live（试用）环境，为 Windows 腾出硬盘空间。

### 1. 制作麒麟启动盘

1. 将第一个空白U盘插入"完备电脑"。
2. 打开 Rufus，选择下载好的银河麒麟ISO镜像。
3. 其他设置保持默认，点击"开始"并确认警告，等待制作完成。
4. 完成后点击关闭，拔出U盘。我们称之为 **【麒麟U盘】**。

### 2. 进入 Live 环境并划分空间

1. 将**【麒麟U盘】**插入联想开天电脑，开机狂按 **F12** 进入启动项选择界面。
2. 选中 `UEFI + 你的U盘名称`，回车。
3. 在启动菜单中，找到并选择 `Try Kylin-Desktop V10-SP1 without installing`（试用而不安装），回车进入 Live 桌面。
4. 点击左下角开始菜单，搜索并打开 **"分区编辑器"**（GParted）。
5. 找到卷标为 `data` 的分区，右键选择**"卸载"**（卸载后分区前方的"锁定/钥匙"图标会消失）。
6. 再次右键该分区，选择 **"调整大小/移动"**，拖动滑块或输入数值，压缩出至少 **50GB**（约51200MB）的"未分配空间"。
7. 点击"调整"，然后点击上方的 **✔️应用/保存**，等待操作完成。
8. 关机，拔出**【麒麟U盘】**。

---

## 🪟 三、制作Win U盘 & 安装Windows系统

### 1. 制作Windows启动盘

1. 将第二个空白U盘插入"完备电脑"。
2. 打开 Rufus，选择下载好的 Windows ISO镜像，默认设置点击"开始"制作。
3. 完成后拔出，我们称之为 **【Win U盘】**。

### 2. 安装Windows系统

1. 将**【Win U盘】**插入联想开天电脑，开机按 **F12** 选择U盘启动。
   > ⚠️ **注意**：此时可能会黑屏等待一小会儿，请勿着急，切勿强制关机。
2. 进入 Windows 安装界面后：
   - 选择语言、时区（默认中国标准时间），点击**"现在安装"**。
   - 版本选择：**Windows 10/11 专业版**。
   - 安装类型选择：**"自定义：仅安装 Windows（高级）"**。
   - 选中我们刚刚在麒麟系统里划分出来的 **"未分配的空间"**，点击"下一步"开始安装。
3. 等待系统安装并自动重启，根据指引完成 Windows 的初始化设置。

## 🌐 四、完善Windows驱动与系统更新

刚装好的 Windows 大概率是没有网络和显卡驱动的，我们需要手动补齐：

### 解决网络问题

1. 打开"计算机管理 -> 设备管理器 -> 网络适配器"，查看带感叹号的WiFi设备（如 `Realtek RTL8852BE WiFi 6 802.11ax PCIe Adapter`）。
2. 用另一台电脑或手机去联想官网/Realtek官网下载对应驱动，用U盘拷入安装；或者使用手机通过USB线连接电脑，开启"USB共享网络"临时上网。

### 安装核心驱动

联网后，前往联想官网或兆芯官网，下载并安装 **兆芯KX7000** 芯片组及核显驱动。

### 系统更新

运行 Windows Update，让系统自动打全剩余驱动和补丁。

## 🔧 五、修复并更新GRUB引导（核心关键步！）

装完 Windows 后，开机可能会直接进入 Windows，丢失了麒麟系统的启动菜单。我们需要通过麒麟的恢复模式把引导"抢"回来。

1. 重启电脑，进入主板 BIOS 或启动菜单，选择从本地硬盘启动，并在出现的 GRUB 菜单中选择**银河麒麟的高级模式（Advanced options for Kylin）**。
2. 选择带有 `(recovery mode)` 或 **恢复模式** 的选项，回车。
3. 在恢复菜单中，选择 **root - Drop to root shell prompt**（进入root命令行），回车获取终端。
4. 依次输入以下两条命令（每输入一条按一次回车）：

   ```bash
   grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
   update-grub
   ```

5. 看到引导更新成功的提示后，输入 `reboot` 重启电脑。
6. ✅ **见证奇迹**：此时开机界面下方会出现"按回车启动选中的操作系统"字样，菜单中同时包含了麒麟和 Windows 选项，选择 Windows 回车，即可顺利进入 Win 桌面！

## ⚙️ 六、设置默认启动系统与等待时间

如果你希望开机默认进入 Windows，或者想调整菜单等待时间，可以进入麒麟系统进行修改。

1. 开机选择进入**银河麒麟系统**。
2. 在桌面空白处右键，选择**"打开终端"**。
3. 输入以下命令并回车（输入密码时不显示，输完回车即可）：

   ```bash
   sudo gedit /etc/default/grub
   ```

   > 💡 **提示**：如果提示找不到 `gedit`，可将命令中的 `gedit` 替换为 `pluma`。

4. 在打开的文本编辑器中，找到并修改以下两行：
   - `GRUB_DEFAULT=0`：`0` 代表默认启动菜单的第一项（通常是麒麟）。如果你想默认启动 Windows，请数一下 Windows 在开机菜单的第几行（从 `0` 开始算）。例如 Windows 在第3行，这里就改为 `GRUB_DEFAULT=2`。
   - `GRUB_TIMEOUT=10`：代表菜单停留的秒数。建议修改为 `5` 或 `10`，避免等待太久或来不及选。

5. 修改完成后，保存并关闭编辑器。
6. 回到终端，输入以下命令使配置生效：

   ```bash
   sudo update-grub
   ```

7. 重启电脑，检查默认启动项是否修改成功！

## 📂 七、双系统文件共享指南

双系统之间如何互传文件？

### 新建共享分区

在磁盘管理中，单独划分一个分区并格式化为 **NTFS 格式**。Windows 和银河麒麟均支持对 NTFS 格式的读写，可作为"公共数据盘"。

### 直接访问

银河麒麟默认支持读取 Windows 的 NTFS 分区。在麒麟的文件管理器左侧，你可以直接点击挂载 Windows 的 C盘、D盘 并访问里面的文件。

> ⚠️ **警告**：在麒麟系统下，请只读取或复制 Windows 盘内的个人文件，**切勿修改、删除 Windows 系统目录**（如 `Windows`、`Program Files`）下的文件，否则会导致 Windows 崩溃！

## 🚨 八、常见问题排查（避坑指南）

| 遇到问题 | 解决方案 |
| :--- | :--- |
| 启动菜单未显示Windows | 进入麒麟系统打开终端，重新执行 `sudo update-grub`。确保Windows是UEFI模式下安装的，且BIOS中未开启冲突的Secure Boot。 |
| 安装Win时提示"无法创建分区" | 检查硬盘分区表是否为GPT格式。若为老旧的MBR格式，需备份数据后通过DiskGenius等工具转换为GPT。 |
| 进入Windows后硬件驱动异常 | 优先前往联想官网输入"联想开天+具体型号"下载官方Win驱动；或使用"驱动总裁/驱动精灵"网卡版进行自动修复。 |
| 双系统切换/运行卡顿 | 兆芯KX7000性能优秀，但双系统对内存要求较高。建议电脑内存 ≥16GB；避免在后台挂载过多不必要的启动项，定期清理系统缓存。 |
